FFmpeg is required for audio conversion. Here's how to install it:

Windows
  1. Download from ffmpeg.org (recommended: "Windows builds from gyan.dev").
  2. Extract the zip to a permanent folder (e.g., C:\ffmpeg).
  3. Add the bin folder to your PATH, or paste the full path to ffmpeg.exe above.
macOS

Install via Homebrew:

brew install ffmpeg

Then paste the output of which ffmpeg into the field above, or leave it empty if it's on your PATH.

A portable executable's exact path can be pasted directly into the field above.
